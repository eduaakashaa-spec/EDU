Bring in the data that is still in Google Sheets

  1. Open the Google Sheet for one assessment, then File → Download → Comma-separated values (.csv).
  2. Choose which assessment it is, attach the file, and import. One row becomes one result.
  3. Columns that hold JSON (for example the full results) are unpacked automatically; student and parent name, email and phone are picked up from common column names.
  4. Importing the same file twice is safe — rows already imported are skipped.
  5. Results are linked to a member automatically when a student or parent email matches an account.
